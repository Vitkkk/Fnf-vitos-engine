# FNF Mobile Studio

Mobile-first Android editor for creating Friday Night Funkin' mods without programming.

This repository is the clean-room project for the no-code/mobile-first editor. The internal project model is engine-independent; Psych Engine compatibility is implemented through exporter profiles instead of being coupled to the editor state.

## V1 target

Create project → Week/Freeplay song → import audio → BPM → characters/stage → chart → test → export a Psych Engine mod.

Development happens on feature branches and is merged through pull requests.
